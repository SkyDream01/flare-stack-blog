# v3.15.0 更新与兼容说明

本分支同步上游 v3.15.0，并保留 `default`、`fuwari`、`cuckoo` 三个主题入口及其配置。

## 更新内容

- 媒体库以及文章封面、头像的图片选择窗口支持从链接导入图片；导入后图片存入媒体库，可直接使用。
- 本地开发服务器新增仅允许本机访问的管理员登录链接，便于在开发工作树中登录和截图。
- 发布与推送检查增加可复用的验证记录，并完善数据迁移和版本发布检查。本分支的构建检查仍覆盖三个主题，首屏资源预算使用 Fuwari 构建。

## 升级与部署

本次没有新增数据库迁移或必填配置，继续使用现有构建与部署流程。从更早版本升级时，仍须阅读此前版本的迁移说明。主题兼容决策见 [ADR 0027](../adr/0027-retain-theme-contract-in-downstream-fork.md)。
