# v3.14.0 更新与兼容说明

本分支从 v3.13.1 同步至上游 v3.14.0，包含 v3.13.2 的修复，并保留 `default`、`fuwari`、`cuckoo` 三个构建入口及其配置。

## 更新内容

- 文章历史页新增「差异」视图，可与当前草稿或上一个历史版本比较，正文按行展示并标出修改的文字，标题、摘要、链接、发布日期、分类、标签和封面的变化单独列出。
- 编辑器「更多操作」新增「查看修改」，对比当前草稿与已发布的版本，包含尚未保存的输入。
- 每篇文章保留最近 20 个历史版本。发布、恢复历史版本或放弃修改产生新版本时，在同一次写入中删除更早的版本。
- 媒体库允许删除仅被历史版本引用的图片。确认框列出受影响的文章数和历史版本数，确认后一并删除图片及这些历史版本。仍被当前草稿、已发布页面或动态引用的图片不能删除。
- 三个主题入口的文章列表统一由点击按钮加载下一页，保留原有布局与外观，页脚不再因滚动加载而不断后移。
- 后台读取单篇文章的 API 增加已发布版本的元数据 `published`，读取历史版本返回解析后的 `cover`；删除媒体支持 `withRevisions` 并返回实际删除的历史版本数。
- 修复 API 一次列出 50 张以上图片时超出 D1 参数数量限制的问题，以及待审核友链申请无法在不发送通知时删除的问题。

## 升级与部署

本次没有新增 SQL 迁移或必填配置，继续使用现有构建与部署流程。从更早版本升级时，仍须阅读此前版本的迁移说明。

已有超过 20 个历史版本的文章不会在升级时被裁剪；下一次产生历史版本时才裁到 20 个。旧版自动保存生成的历史版本继续可查看、恢复和手动删除，也计入上限。删除图片并连同历史版本删除的操作不可恢复，执行前应核对确认框中的影响范围。

`THEME=fuwari` 继续使用上游运行时主题选择；`THEME=default` 和 `THEME=cuckoo` 继续保留本分支的独立页面、布局和专属配置。主题兼容决策见 [ADR 0027](../adr/0027-retain-theme-contract-in-downstream-fork.md)。
