# v3.12.1 upstream sync

Synced from [du2333/flare-stack-blog v3.12.1](https://github.com/du2333/flare-stack-blog/releases/tag/v3.12.1), commit `57581e9d30eb72ab915f1a49e1098f2486a4ba98`. See the [upstream comparison](https://github.com/du2333/flare-stack-blog/compare/v3.12.0...v3.12.1) for the complete change set.

## Changes

- A Moment with one image reserves its image box before the image loads, preventing the card from growing after loading. Known dimensions preserve the image's aspect ratio within the container and height limits; unknown dimensions use a 4:3 box with the image contained inside it.
- Small single images are capped at their natural width. The public Moment card and the shared Moment composer/editor use the same sizing rule, with their existing height limits of `24rem` and `11rem` respectively. Multiple-image grids and the lightbox are unchanged.

## Upgrade

There are no new database migrations, dependencies, environment variables, API contracts or deployment configuration changes compared with v3.12.0. Existing v3.11.0 and v3.12.0 installations can deploy the new build directly. Installations upgrading from v3.10.0 or earlier must also follow [the v3.11.0 migration instructions](./v3.11.0.md).

The [v3.12.0 changes](./v3.12.0.md) were already merged into this fork and were reviewed again for this sync: canonical Post and Moment sharing, Moment image reference counts in the media library, and `GET /api/admin/media/{key}/moments` remain integrated. API clients upgrading from before v3.12.0 should regenerate for that endpoint.

`package.json` is `3.12.1`. The build, generated OpenAPI document, update checks and Agent Skill download/install links derive their release version from it. The existing release configuration names the Agent Skill archive from that version; no separate hard-coded release version is needed.

## Fork integration

- The `default`, `fuwari` and `cuckoo` themes, Theme Contract, registry, build-time `THEME` selection, Site Config fields, static resources and image preloads are retained (ADR 0027).
- Every theme uses the shared Moment card and management components, so all three receive the image fixes without changing their layouts, styling, sharing or comment integrations.
- The six upstream changed paths merged without conflicts. The five Moment implementation/test files match the release tag exactly; the manifest retains the fork's portable TypeScript commands and pinned Noto font dependencies alongside the upstream version bump.
- English and Chinese theme translations, fork deployment/secrets preparation, local Markdown issue tracking, release configuration and the lockfile are retained. Historical release notes remain available; README and deployment instructions point to this release.
