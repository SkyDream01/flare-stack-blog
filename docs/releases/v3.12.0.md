# v3.12.0 upstream sync

Synced from [du2333/flare-stack-blog v3.12.0](https://github.com/du2333/flare-stack-blog/releases/tag/v3.12.0), commit `9c720fd66306dd9a4cff7f89d03d362d49ee4a0f`. See the [upstream comparison](https://github.com/du2333/flare-stack-blog/compare/v3.11.0...v3.12.0) for the complete change set.

## Changes

- Posts and Moments offer a share action. Browsers with native sharing open the system share sheet; otherwise, or if sharing fails, the canonical link is copied with a notification. Cancelling the share sheet does nothing. Post shares include the title; Moment shares use the beginning of their text or the image/video fallback title.
- The media library includes Moment image references in usage counts and lists the referencing Moments in image details. Refused deletions report the Posts and Moments that still reference the image.
- `GET /api/admin/media/{key}/moments` lists the Moments that reference an image, newest first. The existing `/api/admin/media/{key}/posts` endpoint is unchanged.

## Upgrade from v3.11.0

There are no new database migrations, dependencies, environment variables or deployment configuration changes in this release. Existing v3.11.0 installations can deploy the new build directly. Installations upgrading from v3.10.0 or earlier must also follow [the v3.11.0 migration instructions](./v3.11.0.md).

Regenerate API clients to use the new media reference endpoint. The application, generated API contract, update checks and Agent Skill download links derive version `3.12.0` from `package.json`.

## Fork integration

- The `default`, `fuwari` and `cuckoo` themes, build-time `THEME` selection, theme registry, Site Config fields, static resources and image preloads are retained (ADR 0027).
- The Post page contract passes the route's canonical address to all three themes. Fuwari and Cuckoo gain a share button after the content; the default theme's existing share button uses the shared native-share flow and canonical link instead of copying the browser address.
- Moment sharing uses the shared Moment card in every theme. Media library changes and the new Admin endpoint follow upstream.
- English and Chinese messages retain the fork's theme translations and incorporate upstream changes. Obsolete default-theme copy-link messages are removed.
- Fork deployment/secrets preparation, local Markdown issue tracking and the existing lockfile are retained.
