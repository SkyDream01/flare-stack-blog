# v3.13.1 更新与兼容说明

本分支从 v3.12.1 同步至上游 v3.13.1，包含 v3.13.0 的完整更新，并保留 `default`、`fuwari`、`cuckoo` 三个构建入口。

## 更新内容

- 管理后台采用上游新版界面，新增「个性化」、主题预览、概览中的版本更新详情、忽略提醒与升级后提示。
- `THEME=fuwari` 使用上游新版共享页面，可在「个性化」中切换经典、名片、沉浸、侧栏四套运行时主题，无需重新构建。
- `THEME=default` 和 `THEME=cuckoo` 保留原有页面与布局，专属配置在「个性化」中维护。运行时主题选择仅适用于 Fuwari 构建入口；另外两个入口仍通过 `THEME` 选择。
- 公共页面、图片、代码块、登录会话、配色切换和 Agent Skill 分发同步上游改进。原有主题继续复用共享内容渲染器，保留各自图片和代码框的外观。
- 自托管 Umami 的热度同步使用其自身 API。3.4.0 及以上的自托管 Umami 可使用 `UMAMI_API_KEY`；API 地址按 `UMAMI_SRC` 判断。
- `cf` CLI 更新至 `1.0.0-beta.29`，图片转换使用 Worker 的 `IMAGES` 绑定。

## 升级与部署

本次没有新增 SQL 迁移或必填环境变量。部署仍执行迁移命令，以应用此前尚未执行的迁移。从 v3.10.0 或更早版本升级，还须遵循 [v3.11.0 迁移说明](./v3.11.0.md)。

GitHub Actions 与 `bun run deploy` 均在数据库迁移前执行部署前检查，并在 Worker Version 上记录应用版本标签。跨大版本更新时，应先阅读检查结果并完成其中要求的准备事项。

后台更新检查读取上游 `upgrades.json`，不再需要 `GITHUB_TOKEN`。GitHub OAuth 的 `GITHUB_CLIENT_ID` 和 `GITHUB_CLIENT_SECRET` 仍需保留。

已有 `theme.default`、`theme.cuckoo` 配置继续保存。旧 `theme.fuwari` 的背景、头像和色相会迁移为共享展示字段，并保留兼容副本。

主题兼容决策见 [ADR 0027](../adr/0027-retain-theme-contract-in-downstream-fork.md)。
