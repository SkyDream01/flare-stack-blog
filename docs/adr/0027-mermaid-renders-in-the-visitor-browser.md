# Mermaid renders in the visitor's browser

A Mermaid diagram is a code block whose language is `mermaid`. The Public Content Snapshot stores it like any other code block, with Shiki-highlighted source, and the public page turns that source into a diagram in the visitor's browser. This departs from the rule that public pages show snapshot HTML only. Pre-rendering the SVG on publish is not possible: Mermaid needs a DOM, which the Worker and the PostPublisher Durable Object do not have, and a Post published with an API Key has no browser involved. So the snapshot keeps the source as the fallback that RSS, the JSON Feed, the search index and readers without JavaScript see, and only posts that contain a Mermaid block load Mermaid. Mermaid is imported only on the client path (an effect, behind an SSR check), because the Worker is one module and any dynamic import reachable from server code would be inlined into it. Diagrams use `securityLevel: "strict"` so content cannot run scripts or click callbacks, and take their colours from the Fuwari tokens (ADR 0021), re-rendering when the site theme changes.
